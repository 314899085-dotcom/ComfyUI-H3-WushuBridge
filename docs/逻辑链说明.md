## 0. H3 常见翻车 → 桥要学的差向量（优先）

用户实测生成里，下列六类失败**反复出现**。v1.1+ 用「正例种子 − 定向降级负例」把它们写进训练差向量；
评分头也会对正例扣分。

| # | 翻车现象 | 正例必须写清 | 降级算子（制造负例） | 评分检查 id |
|---|---|---|---|---|
| 1 | 无意义跳跃 / 腾空无起落力 | 蹬地借力起跳 + 落地屈膝卸力 | `jump_orphan` | `jump-with-cause` |
| 2 | 人物打斗没有面对面 | 每拍「面对面 / 面向对方 / facing」 | `facing_break` | `facing-lock` |
| 3 | 法术不是打向对手（打空气） | 「朝角色B / aimed at opponent chest」 | `spell_miss_target` | `spell-target` |
| 4 | 切镜换人 / 位置瞬变 | 每镜「仍是同一张脸…」+ 位置连续 | `identity_drift` / `teleport_cut` | `identity-lock` / `spatial-lock` |
| 5 | 空间逻辑弱（左右/间距/朝向乱） | 每镜开头重申左/右/间距N格/朝向，**优先显式 xyz** | `teleport_cut` / `facing_break` / `xyz_drift` | `spatial-lock` / `xyz-lock` |
| 6 | 法术击中后无物理反馈 | 击中后踉跄/衣灼/击退/闷哼 | `spell_no_feedback` | `spell-hit-feedback` |

相关词表：`FACING_LOCK` / `JUMP_BARE`+`JUMP_CAUSE` / `SPELL`+`SPELL_TARGET` / `IDENTITY_LOCK` / `SPATIAL_OPEN` / `XYZ_LOCK` / `SPELL_FEEDBACK`（见 `lexicons.py`）。

示范链：`face_to_face_duel` / `jump_takeoff_land` / `spell_aimed_feedback` / `cross_shot_identity_space` / `xyz_coord_duel`。

示范种子：`seeds.SEED_T2V` 第 9–12 条 + XYZ 中英条 + Ref2V 法术面对面 / XYZ 条。

## XYZ 坐标约定

相机相对地面坐标系（写进提示词时建议每镜开头重申）：

| 轴 | 含义 | 符号 |
|---|---|---|
| **X** | 画面左右 | 左 (−) / 右 (+) |
| **Y** | 纵深 | 靠近相机 (−) / 远离 (+) |
| **Z** | 离地高度 | 0 = 站立双脚着地 |

单位：抽象「步」≈ 一个武打步距。典型对决：A@`(-2,0,0)`，B@`(+2,0,0)`，面对面。

规范写法：

* ZH：`角色A@xyz=(-2,0,0)` 或 `位于 xyz=(-2,0,0)`
* EN：`<Subject 1> at xyz=(-2,0,0)`
* 连续性格：`坐标锁定：A@xyz=(-2,0,0) 面向 B@xyz=(2,0,0)；切镜后重申相同 xyz，仅在位移动作后更新`
* EN：`coords locked: A@xyz=(-2,0,0) facing B@xyz=(2,0,0); restate same xyz after cuts; update only after explicit footwork`

亦接受：`xyz=(-2, 0, 0)` / `XYZ(-2,0,0)` / `坐标(-2,0,0)` / `at (-2,0,0)`（靠近主语时）。

降级算子 `xyz_drift` 会扰动或剥掉这些坐标；评分检查 `xyz-lock` 偏好带 xyz 的多镜对决，并对无位移大跳扣分。

## 1. 链家族一览

实现：`wushu_bridge/logic_chains.py` → `CHAINS`。

### A. 打斗动作链（完整弧）

| 短名 | 中文 | 关键槽位 |
|---|---|---|
| `duel_basic` | 逼近→测距→攻→防/反→接触→力反馈→状态→追击/终结 | force, distance, defense, contact, feedback, state_carry |
| `clinch_break_punish` | 缠抱→拆开→惩罚 | distance, force, defense |
| `feint_commit_punish` | 佯攻→实打→惩罚落空 | moves, facing, feedback |
| `disarm_reclaim` | 缴械→夺回或徒手续战 | ownership, contact |
| `wall_rebound` | 击退撞墙→反弹→动量继承续打 | momentum, force |
| `multi_handoff` | 多人：谁打谁、下一拍谁接手 | handoff, facing |
| `aerial_jump` | 起跳借力→空中轨迹→落地卸力 | aerial, force |
| `counter_punish` | 防守反击→惩罚空档 | defense, causal |
| `xyz_coord_duel` | XYZ坐标对决：锁坐标→步法更新→切镜重申→法术沿向量 | xyz, facing |

## 2. 降级算子 ↔ 链家族对照

| 新算子 | 破坏什么 | 对应链 |
|---|---|---|
| `ownership` | 握持/捡回/归属 | disarm_reclaim, weapon_ownership, weapon_handoff |
| `occlusion` | 「同一张脸/服装」锁 | occlusion_reappear |
| `facing` | 左右/朝向 | facing_swap, pursuit_reengage |
| `momentum` | 击退→反弹→动量 | wall_rebound, aerial_jump |
| `pursuit` | 追击/刹停再交手 | pursuit_reengage |
| `state_carry` | 伤势/状态跨镜 | injury_state_carry, env_continuity |
| `chain_break` | 删「于是/顺势/therefore」 | 所有弧的因果粘合剂 |
| `xyz_drift` | 扰动/剥掉显式 xyz 坐标 | xyz_coord_duel, face_to_face_duel |

经典算子仍在：`force_chain / distance / contact / feedback / defense / moves / ending`（+ `empty/junk/holes/sound/order`）。

**默认档案 `DEFAULT_OPS` = 经典逻辑 + 高动态**（`pairs.DegradeProfile` 留空 ops 时启用）。
