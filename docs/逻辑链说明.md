# 武打因果逻辑链说明（v1.1 · BUNNY 高动态家族启发）

> 灵感：[BUNNY H3 Conditioning Bridge V2](https://huggingface.co/JOKER141/BUNNY_H3_Conditioning_Bridge)
> 覆盖：追逐、武器脱手与回收、遮挡后身份恢复、动量继承、撞墙反弹、多人交接、战斗状态继承、相对朝向等。
> 本仓库把上述概念落到 **WUSHU 对决域**，用「完整因果弧 + 定向降级」教桥补逻辑。

## 1. 链家族一览

实现：`wushu_bridge/logic_chains.py` → `CHAINS`。

### A. 打斗动作链（完整弧）

| 短名 | 中文 | 关键槽位 |
|---|---|---|
| `duel_basic` | 逼近→测距→攻→防/反→接触→力反馈→状态→追击/终结 | force, distance, defense, contact, feedback, state_carry |
| `clinch_break_punish` | 缠抱→拆开→惩罚 | distance, force, defense |
| `feint_commit_punish` | 佯攻→实打→惩罚落空 | moves, facing, feedback |
| `disarm_reclaim` | 缴械→夺回或徒手续战 | ownership, contact |
| `wall_rebound` | 击退撞墙→反弹→动量继承续打 | momentum, force |
| `multi_handoff` | 多人：谁打谁、下一拍谁接手 | handoff, facing |
| `aerial_jump` | 起跳借力→空中轨迹→落地卸力 | aerial, force |
| `counter_punish` | 防守反击→惩罚空档 | defense, causal |

### B. 非动作 / 行为与连续性链

| 短名 | 中文 | 关键槽位 |
|---|---|---|
| `weapon_ownership` | 谁握持、脱手后谁捡回 | ownership |
| `occlusion_reappear` | 遮挡后入画仍是同一张脸/服装/武器 | occlusion |
| `facing_swap` | 换位后左右与朝向锁定 | facing |
| `pursuit_reengage` | 追击→超步→刹停再交手 | pursuit |
| `cover_debris` | 掩体破碎→碎屑跨镜继承 | cover, env_continuity |
| `ricochet_geometry` | 弹刀后刃路几何延续 | ricochet |
| `injury_state_carry` | 伤肩仍受限等跨镜继承 | state_carry |
| `env_continuity` | 湿石仍湿、尘土留痕 | env_continuity |
| `weapon_handoff` | 主动换手/递兵 | ownership |

调用：

```python
from wushu_bridge.logic_chains import render_chain_text, validate_chain_coverage, list_chains

print(validate_chain_coverage(seed_text, "duel_basic"))
```

编舞侧轻量导出：`choreography.list_logic_chain_presets()`。

## 2. 降级算子 ↔ 链家族对照

| 新算子 | 破坏什么 | 对应链 |
|---|---|---|
| `ownership` | 握持/捡回/归属 | disarm_reclaim, weapon_ownership, weapon_handoff |
| `occlusion` | 「同一张脸/服装」锁 | occlusion_reappear |
| `facing` | 左右/朝向 | facing_swap, pursuit_reengage |
| `momentum` | 击退→反弹→动量 | wall_rebound, aerial_jump |
| `pursuit` | 追击/刹停再交手 | pursuit_reengage |
| `state_carry` | 伤势/状态跨镜 | injury_state_carry, env_continuity |
| `chain_break` | 删「于是/顺势/therefore」 | 所有弧的因果粘合剂 |

经典算子仍在：`force_chain / distance / contact / feedback / defense / moves / ending`（+ `empty/junk/holes/sound/order`）。

**默认档案 `DEFAULT_OPS` = 经典逻辑 + 高动态**（`pairs.DegradeProfile` 留空 ops 时启用）。

## 3. 词表与评分

* `lexicons.py`：新增 OWNERSHIP / OCCLUSION / MOMENTUM / PURSUIT / FACING / COVER / STATE_INHERIT / RICOCHET / ENV_CONTINUITY / AERIAL / HANDOFF，已并入 `slots_present()`。
* `logic_score.py`：为上述槽位加软评分；因果链要求更严（≥2 连接词）；多镜继承加分项。
* ``logic_score.py`：多镜状态/身份/环境继承为加分项（不改 h3lint/JS 体检契约）。
